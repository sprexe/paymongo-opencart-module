# PayMongo Upgrade Module for OpenCart

PayMongo payment integration upgrade module for OpenCart.

## Compatibility

- OpenCart 2.x
- OpenCart 3.x

## Module Packages

### OpenCart 2.x

`paymongo.OC2.ocmod.zip`

### OpenCart 3.x

`paymongo.OC3.ocmod.zip`

## Installation

1. Download the appropriate OCMOD package for your OpenCart version.
2. Log in to the OpenCart Administrator panel.
3. Go to **Extensions → Extension Installer**.
4. Upload the corresponding `.ocmod.zip` package.
5. After installation, go to **Extensions → Modifications**.
6. Click **Refresh** to apply the modification.

## Package Files

| OpenCart Version | Package |
|---|---|
| OpenCart 2.x | `paymongo.OC2.ocmod.zip` |
| OpenCart 3.x | `paymongo.OC3.ocmod.zip` |
