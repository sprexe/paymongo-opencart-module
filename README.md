# PayMongo Upgrade Module for OpenCart 2.x

PayMongo payment integration upgrade module for OpenCart 2.x.

## Compatibility

- OpenCart 2.x

## Installation

1. Download `paymongo.OC2.ocmod.zip` from this repository.
2. Log in to the OpenCart Administrator panel.
3. Go to **Extensions → Extension Installer**.
4. Upload the `paymongo.OC2.ocmod.zip` package.
5. After installation, go to **Extensions → Modifications**.
6. Click **Refresh** to apply the modification.

## Module Package

The ready-to-install OpenCart 2.x package is included in this repository:

`paymongo.OC2.ocmod.zip`

## Notes

This module is provided as an OpenCart OCMOD package and is intended for OpenCart 2.x installations.
